derivation

Every node file carries identity, provenance and append-only estimate records. A reviewer reading a diff cannot confirm that an ID is well formed, that a reference resolves, or that an estimate record was added rather than quietly rewritten. Without a machine check the discipline is a convention, and conventions decay under time pressure.
