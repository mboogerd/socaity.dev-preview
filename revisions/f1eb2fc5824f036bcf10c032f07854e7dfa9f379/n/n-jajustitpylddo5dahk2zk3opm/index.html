Render a static site from the YAML node files

Open currently favored

Asserted by decomposer, on behalf of founder · written by a program · estimated 2026-08-02

One small Python generator reads graph/nodes/*.yaml and writes a static site: one page per node, a roadmap page, an /all index and a graph.json export. The site is a pure function of the merged tree, so a fork renders the same pages and CI can prove the build is reproducible.

Why this edge: A published, forkable site is one way to make the open work visible.
